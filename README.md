# Happy Little Mail

Shareable landing page for a tiny monthly envelope of joy. No checkout. No email form.

## Open or share

- Open `index.html` in a browser
- Or serve the folder: `python3 -m http.server 8080`
- GitHub: [Chemist5/happy-little-mail](https://github.com/Chemist5/happy-little-mail)
- Vercel: import this repo as a static site (`vercel.json` is included)

## Product photo

In `index.html`, find `figure#product-photo`. Replace the dashed placeholder with:

```html
<img src="product.jpg" alt="A Happy Little Mail envelope filled with tiny stationery">
```

Add `product.jpg` (or your filename) next to `index.html`.
